# 命名由來與決策紀錄

## 最終名稱

- 專案名稱：**Kaeru Tunnel**
- Repo：`kaeru-tunnel`（GitHub 慣例全小寫＋連字號）
- 未來 LuCI 套件：`luci-app-kaeru-tunnel`
- 吉祥物：🐸

## 由來

- 日文「帰る（かえる）」＝回家，與「蛙（かえる）」同音
- 日本有一種很有名的青蛙御守，取「無事カエル」的諧音，意思是「平安回家」——這正是這個專案在做的事
- 「Tunnel」點出功能：一條連回家的通道

## 考慮過的名稱

| 名稱 | 結果 | 原因 |
|---|---|---|
| Homeward（回家路） | 未採用 | 好懂，但太普通、缺少故事 |
| Kaeru | 未採用 | 好記，但光看名字看不出功能 |
| KaeruVPN | 未採用 | 一看就懂是連線工具，但「VPN」容易被誤會成翻牆、換 IP 的商業 VPN |
| KaeruRemote | 未採用 | 太籠統，容易被當成遙控器 app |
| Porchlight（門廊燈） | 未採用 | 語氣溫暖，但是常見英文名 |
| Tadaima（ただいま） | 備用 | 可作為手機連上家裡時的畫面文字 |
| **Kaeru Tunnel** | **採用** | 有故事、有功能詞，且不會與商業 VPN 混淆 |

## 要避開的名稱

- `wg-easy`：已有知名的 Docker 專案
- `unetd`：OpenWrt 官方的 WireGuard mesh VPN 背景服務

## 注意

在自架圈子裡，「tunnel」常讓人想到 Cloudflare Tunnel 這類「把家裡服務公開到網路上」的工具。所以對外介紹的第一句一律寫清楚：**連回自己家**。
